Basic Relay (10 seconds)

# Run on default port 4444
npx fonstr

# Done! Your relay is live at:
# - Nostr relay: ws://localhost:4444/relay
# - Web server: http://localhost:4444

Custom Port

# Run on port 8080
npx fonstr 8080

# Or use environment variable
PORT=8080 npx fonstr

With Landing Page

# Create your landing page
mkdir fonstr-data
cat > fonstr-data/index.html << 'EOF'
<!DOCTYPE html>
<html>
<head><title>My Nostr Relay</title></head>
<body>
  <h1>⚡ Welcome to My Relay</h1>
  <p>Connect: ws://localhost:4444/relay</p>
</body>
</html>
EOF

# Start relay
npx fonstr

# Visit http://localhost:4444 to see your page!

Production with HTTPS

# Get SSL certificates (Let's Encrypt)
# Place fullchain.pem and privkey.pem in current directory

# Run with HTTPS
npx fonstr --https --port 443

# Now accessible at wss://yourdomain.com/relay
